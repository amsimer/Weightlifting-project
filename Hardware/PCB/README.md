# PCB files

This folder contains the KiCad design files and fabrication outputs for the POWER CABLE V2 printed circuit board.

## Design files

- `pcb.kicad_pro` — KiCad project
- `pcb.kicad_sch` — schematic
- `pcb.kicad_pcb` — PCB layout

## Manufacturing files

The `Manufacturing/` folder contains the Gerber, drill and job files required by a PCB manufacturer.

Review the fabrication settings and board specifications with the selected manufacturer before ordering.
